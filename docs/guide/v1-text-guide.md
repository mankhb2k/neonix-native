# MotiClip V1 Text

> Trạng thái: nháp
>
> Mục tiêu: nội dung chữ và hộp chữ cho AI viết JSON.

---

## Đã chốt

- Text là leaf.
- `frame` bắt buộc: size box cho wrap / overflow / alignment.
- Rich text runs thuộc semantic text, không thuộc generic modifier.
- Paint / typography nằm trên layer text.

---

## Còn mở

- Luật mặc định chính xác cho wrap, overflow, line height, alignment khi AI bỏ trống.
- Hành vi kiểu counter có vào bề mặt AI đợt đầu không.
