# MotiClip V1 Variables và Bindings

> Trạng thái: nháp
>
> Mục tiêu: luồng dữ liệu tái sử dụng cho JSON do AI sinh.

---

## Đã chốt

- Variable là giá trị có kiểu.
- Binding nối variable tới property của layer hoặc public prop của component.
- Binding thuộc bề mặt authoring ưu tiên (khác `modifiers`).
- `semantic` là metadata; không thay variable.

---

## Còn mở

- Subset property được bind trên bề mặt AI-safe.
- Target nào nên ẩn khỏi docs mặc định cho đến khi preview/export đủ parity.
- Ví dụ nên ưu tiên literal hay giá trị qua variable.
